# 🚀 Personal Portfolio

A personal portfolio website to showcase my skills, projects, and experiences. Built using modern web technologies like Vite, TypeScript, and Tailwind CSS.

**🌐 Live Site:** [https://velprakash.netlify.app](https://velprakash.netlify.app)

---

## 🛠️ Technologies Used

- **Framework:** Vite  
- **Languages:** TypeScript, JavaScript  
- **Styling:** Tailwind CSS  
- **Build Tools:** Vite  
- **Configuration:** ESLint, PostCSS

---

## 🚀 Getting Started

Follow these steps to set up the project locally:

### Prerequisites

- [Node.js](https://nodejs.org/)
- [Git](https://git-scm.com/)

### Installation

```bash
# Clone the repository
git clone https://github.com/Velprakash0611/portfolio.git

# Navigate to the project directory
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

Then open your browser and go to:

```
http://localhost:5173
```
